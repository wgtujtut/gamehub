# GameHub

Игровая панель для Windows: считает, сколько ты играешь, собирает все игры в одну библиотеку и следит за бесплатными раздачами.

## Что умеет

- **Учёт времени.** Сам находит игры Steam (все библиотеки), Epic Games и Escape from Tarkov. Пишет каждую сессию, показывает часы за день, неделю и месяц, серию дней подряд и тепловую карту года.
- **Библиотека.** Все игры с обложками, запуск одной кнопкой, список «давно не играл»: сколько места можно освободить.
- **Халява.** Бесплатные игры в Epic, Steam и GOG и уведомление, когда появляется новая.
- **Режим игры.** Во время игры включает максимальный план питания и, если хочешь, закрывает тяжёлые фоновые программы. После игры возвращает всё как было.
- **Чистка.** Кэши Discord, браузеров, Steam и временные файлы. Игры и сохранения не трогаются.
- **Пинг.** График задержки до серверов и средний пинг каждой сессии.

Работает тихо в трее. Окно закрывается крестиком, а учёт игр продолжается.

## Установка

1. Скачай `GameHub-Setup-x.y.z.exe` со страницы [Releases](https://github.com/wgtujtut/gamehub/releases/latest).
2. Запусти. Права администратора не нужны.
3. Если Windows покажет окно «Windows защитил ваш компьютер», нажми **Подробнее → Выполнить в любом случае**. Так бывает с любой программой без платной цифровой подписи.

Обновления GameHub находит сам и предлагает поставить их одной кнопкой.

Нужна Windows 10 или 11 (64 бит). Твои данные хранятся в `%APPDATA%\GameHub`.

## Для разработки

```
python -m venv .venv
.venv\Scripts\pip install -r requirements-lock.txt
.venv\Scripts\python -m pytest -q        # тесты
.venv\Scripts\python app.py              # запуск из исходников
.venv\Scripts\python build.py            # установщик → dist\
```

Для сборки установщика нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).
